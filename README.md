# Lahari — AI/ML Portfolio

A static, responsive portfolio website for Lahari, built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Free deployment

### GitHub Pages
1. Create a GitHub repository named `lahari-portfolio`.
2. Upload everything in this folder.
3. In GitHub: **Settings → Pages → Deploy from branch → main → / (root)**.
4. Save. GitHub will give you a free `github.io` address.

### Vercel
Import the GitHub repository into Vercel and deploy with the default settings. The free Hobby tier is enough for a personal portfolio.

## Personalize before publishing

Replace the placeholder GitHub and LinkedIn URLs in `index.html` with your real profiles.

The resume and cover letter are included under `assets/`.
